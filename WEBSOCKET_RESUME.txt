🔌 ÉVÉNEMENTS PRINCIPAUX

Réception (serveur → client):
  📊 sensor-data-update    // Données capteurs
  ⚙️  controls-update      // Configuration actuelle

Envoi (client → serveur):
  🚰 update-irrigation     // Contrôler l'irrigation
  💧 update-misting        // Contrôler la brumisation
  💨 update-ventilation    // Contrôler la ventilation
  🔥 update-heating        // Contrôler le chauffage

Statut:
  ✅ success               // Action réussie
  ❌ error                 // Erreur serveur
  🔗 connected             // Connecté
  ⚠️  disconnected         // Déconnecté

💡 EXEMPLE D'UTILISATION

// 1. Initialiser
await wsClient.connect();

// 2. S'abonner aux données
wsClient.on('sensor-data', (data) => {
    console.log('Température:', data.temperature + '°C');
    updateDisplay(data);
});

// 3. Envoyer une commande
wsClient.updateIrrigation('active', 40);

// 4. Recevoir la confirmation
wsClient.on('server-success', (msg) => {
    console.log('✅', msg);
});

📊 COMPARAISON: AVANT vs APRÈS

Métrique              AVANT (REST)    APRÈS (WebSocket)
─────────────────────────────────────────────────────
Latence              5-10 secondes   < 100 millisecondes
Requêtes/minute      12+             0 (connexion persistante)
Bande passante       Élevée          Minimale
CPU Serveur          Moyen           Bas
Synchronisation      Manuelle        Automatique
Multi-clients        ❌              ✅ Broadcast auto

❓ DÉPANNAGE

Problème: "WebSocket pas connecté"
→ Vérifier que le serveur est démarré (npm start)

Problème: "Non authentifié"
→ Token JWT expiré, se reconnecter après login

Problème: "wsClient is not defined"
→ Vérifier l'ordre des scripts dans index.html

Problème: "Connection refused"
→ Vérifier le port et l'adresse IP
